- 새 이미지에서 실제 제한 계정·owner readback을 사용해 두 목적의 Key 변경·미등록/반복 요청·감사 실패 롤백·형식 오류와 시도 제한·현재 세션 및 작업 중 만료를 검증. SQL 한도 시험은 계산된 런타임 상한과 기존 SQL 형식v1 제약의 일치를 확인한다.
- 긴 입력 시험은 실제 컴파일된 inspector를 별도 프로세스에서 실행하고 네트워크/개인 .env 읽기를 차단한다. 20만 자 수준 LF/CRLF/수평 공백에서도 일반 내용·이어지는 비밀 패턴을 각각 검사한다. 기존 regex로 빌드 산출물만 임시 되돌리면5초 timeout으로 실패했고 산출물을 복구한 뒤 배포18개를 통과했다.
- prepare CLI의 엄격 인코딩·크기 제한·기존 파일 보존을 임시 디렉터리에서 검증. 평문 Buffer 정리 시험은 유효 tag와 유효 인코딩의 잘못된 tag 양쪽을 실제 Node crypto로 수행한다.
- 최종 runtime 이미지의 별도 비특권·읽기 전용 합성 컨테이너에서 Key/정책 저장→컨테이너 교체→같은 master로 재조회→비활성화/삭제→로그아웃 후 거절을 확인. master/Key는 합성 자료이며 실제 provider 호출 없음.

실모델·가격/usage/비용·운영 TLS·설정 웹·전체 백업/복구는 여전히 후속 범위다. 이번 수정은 C 전체 완료가 아니다. 반복 리뷰의 핵심은 분기 시험이 기본 embedding 목적에 치우쳤고, 잘못된 인코딩 시험으로 실제 인증 변조 검증을 대신했던 점과 무변경 감사/긴 입력/명령의 엄격 형식 경계를 놓친 점이다. 해당 경계를 목적별·유효 형식 유지·실제 처리 시간·저장 readback 기준으로 보완했다.
