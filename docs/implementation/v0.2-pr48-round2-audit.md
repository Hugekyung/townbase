## 중요한 회귀와 원인

백업의 spawn import를 제거하고 남은 streamIn/Out 사용처를 놓쳤다. 평가 runner는 범위가 제한되지 않은 문자열 치환으로 본체 초기화를 finally에도 복제했다. API 중심 build/lint/test는 이 JS CLI와 ts-node 평가 스크립트의 정상/실패 종료를 실행하지 않아 결함을 잡지 못했다. 이전 통과 집계는 유효한 시험 범위의 결과지만 수정된 백업 CLI와 평가 runner 전체 검증으로 설명하기에는 부족했다.

백업은 수정 전 병합을 권하지 않는다. spawn 누락은 실제 정적 코드상 확정적 ReferenceError이며 대용량/실계정 호출 없이도 재현할 수 있다. 평가 finally도 공급자를 합성 구현으로 바꾼 성공/실패 실행 시험이 필요하다.
