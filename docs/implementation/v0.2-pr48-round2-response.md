## 남은 운영/증거 경계

로컬 Docker CLI 종료를 daemon 내부 pg_dump/psql 종료로 단정하지 않는다. 실패 restore는 marker 뒤 API 중지 상태이며 운영자가 대상 상태를 확인해야 한다. 종료 미확인 자식의 실제 OS D-state를 만들어 검증하지는 않았으며 fake ChildProcess로 bounded 실패/정리 불허 계약만 확인했다.

과거 manifest와 실계정 원자료는 변경하지 않았다. source SHA는 운영자 확인값이고, 초기 실행의 단일 policy hash를 전체 컴포넌트 식별로 확대하지 않는다. 최신 코드의 실제120문항 유료 품질 평가는 재실행하지 않았다. 전체 AT/OP의 부분 확인/N/A도 유지한다.

초기 감사는 [audit](v0.2-pr48-round2-audit.md), 실행 안내는 [백업/복원](../backup-and-restore.md)을 따른다.
