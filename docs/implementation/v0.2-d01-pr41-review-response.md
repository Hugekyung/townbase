## 재현·범위

일반 검증은 Node24에서 다음 명령을 각각 실행한다.

```sh
pnpm build
pnpm lint
pnpm test
pnpm test:deployment
```

업그레이드 통합 시나리오는 일반 test:deployment에 포함되지 않는다. migration 이미지에서 `TOWNBASE_FILE_PREFLIGHT_TEST=1`과 정확한 postgres/townbase_d01_pr41_preflight_test의 새 빈 DB, DB 소유자·runtime secret 환경으로 `node --test deployment/test/file-extraction-preflight.integration.mjs`를 명시 실행한다. 시험은 구버전 schema·합성 데이터·migration 이력을 생성하며 기존 DB를 자동 초기화하지 않는다. 현재 적용 이력이 있는 DB에서는 시작을 거절한다. 반복하려면 운영 DB와 구분한 이 전용 시험 DB만 운영자가 명시적으로 재생성해 같은 이름의 빈 DB를 준비해야 한다.

기존 D01 DB suite의 guard와 실행 조건은 [이전 대응 기록](v0.2-d01-review-response.md)을 따른다. 로컬 증거는 /tmp/townbase-pr41-{build,lint,api,control,deployment,preflight-unit,integration,d01-db,image,runtime}.log와 /tmp/townbase-pr41-real-child.cjs에 있다. 신규 통합 runner는 /tmp/townbase-v02-b04/pr41-preflight-integration.mjs다.

사용자 요청에 따라 검증 요약 후 커밋·푸시·PR 댓글로 전달한다. 공개 업로드/임베딩·재시작 파일 orphan 복구는 이번 범위에 추가하지 않는다.


Compose 재현 예시(프로젝트 이름/설정 파일은 실제 시험 설치에 맞춤): PostgreSQL이 실행 중이고 위 전용 DB가 새 빈 상태이며 최신 migration 이미지가 빌드돼 있어야 한다.

```sh
docker compose --env-file .townbase/compose.env -p my-townbase run --rm --no-deps -e TOWNBASE_RUNTIME_PROFILE=self_hosted -e POSTGRES_DB=townbase_d01_pr41_preflight_test -e TOWNBASE_FILE_PREFLIGHT_TEST=1 --entrypoint node migration --test deployment/test/file-extraction-preflight.integration.mjs
```
