## 검증

최종 Linux amd64 컨테이너에서 Jest 63 suites / 209개와 Node 배포 시험2개, **총211개 통과**. 호스트 Node24.19.0·pnpm10.33.2에서도 빌드·API75개·배포2개·API lint 통과. 호스트 HTTP 시험은 샌드박스의 임시 포트 제한 때문에 허용된 별도 실행에서 확인했다.

| --- | --- |
| 빈 volume 기동 | DB health → node migration exit0 → 제한 계정 API healthy, readyz200 |
| DB 계정 | current_user=townbase_runtime. superuser/DB 생성/역할 생성/replication/RLS 우회 모두 false |

## 현재 제한

- API의 DB 쓰기는 아직 제품 기능으로 제공하지 않는다. B03 이후 각 기능에 필요한 테이블 권한은 해당 구현에서 명시적으로 추가한다. 미래 테이블 전체에 대한 자동 권한 부여는 없다.
- 파일 probe는 검사 시점의 작은 쓰기 가능 여부를 확인한다. 모든 향후 대용량 저장 성공이나 실제 디스크 전체 고장 시험을 뜻하지 않는다. 디스크 가득 참은 실패 주입 시험으로 검증한다.
- 기존 도입 환경에 자동 적용하거나 운영 DB를 변경하지 않았다. 별도 시험 프로젝트·합성 비밀·빈 volume과 전용 test DB를 사용한다.
