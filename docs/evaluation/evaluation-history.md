# 평가와 개선 이력

Workspace Knowledge Agent(townbase)의 평가 결과와, 평가에서 드러난 문제를 어떻게 보완했는지 시간 순으로 모은 기록이다. 각 수치의 조건·분모·한계는 링크한 원본 기록을 따른다. 이 문서는 요약이며 원본 기록을 대신하지 않는다.

마지막 갱신: 2026-11-17

## v0.1 — MCP 평가 (2026-08-25)

Keeply 문서 21개·Golden Question 23개를 MCP `auto` 모드로 평가했다.

- 최종 답변은 23/23이 기대 결론에 도달했다.
- RAG 출처만으로 정답 문서를 찾은 문항은 17/23(Hit@K 73.9%)이었다. 19/23은 `sourcePacket`을 반환했고, 나머지는 Agent의 이전 문맥이 답변을 보완한 사례가 포함됐다.
- 최종 답변 성공률과 RAG 검색 성공률을 분리해야 한다는 점을 확인했다. 검색이 실패한 질문은 사용자별 local memory에 따라 답변 재현성이 달라질 수 있다.

[상세 기록](../../evaluation-20260825.md)

## v0.2 — 실계정 합성 평가 (2026-11-08)

공개 합성 문서 두 집합(OPS·SHOP, 각 12문서·PDF/DOCX/MD/TXT 각 3개)과 집합별 60문항을 `gpt-6-luna`·추론 강도 low로 3회씩 실행했다. 질문마다 새 대화이며, 실제 업로드·추출·명시 색인과 비용 예약을 거쳤다.

| 지표 | 결과 (6회차) | 기준 |
| --- | --- | --- |
| Hit@5 | 50/50 (모든 회차) | 90% |
| 출처 정확성 (보수 채점) | 96.8%~100% | 95% |
| 답변 가능/불가 판정 | 59~60/60 | 90% |
| 근거 없는 질문의 오답 | 0/10 (모든 회차) | 0/10 |
| 충돌 탐지 | 10/10 (모든 회차) | 10/10 |
| 전체 답변 p95 | 2.95~3.47초 | 45초 |
| 검색·접근·근거 패킷 p95 | 37.5~55.9ms | 2초 |
| 실계정 비용 | 약 US$0.185 (미확정 예약 포함) | 승인 상한 US$1 |

- 모든 회차가 품질 기준을 충족했다. 유일한 판정 오류는 SHOP 3회차 Q21의 과잉 거절이다.
- 첨부 작업은 4형식×요약/질문/초안 12개가 모두 answered였고, 공용 Document/Chunk/Gap/draft 개수는 0→0으로 전파되지 않았다.
- 한계: 구현 Agent가 채점한 공개 합성 회귀이며 독립·블라인드 평가가 아니다. ARM 호스트의 amd64 에뮬레이션 환경이다. 실제 고객 문서·200문서/5,000조각 규모로 일반화하지 않는다.

## 첫 실제 도입 문서 — 행복주택 공고 PDF 15문항

합성 평가와 달리 실제 공고 PDF(32쪽, 표·각주·예외 목록이 많음)에서는 답변 품질이 낮았다. 사용자가 [고정 15문항](v0.2/housing-20260721-questions.json)을 직접 묻고 문항별 2/1/0점으로 채점했다(총 30점, 목표 26점). 진단용 체감 점수이며 정식 품질 지표와 별개다. 루브릭과 단계(R01~R07)는 [품질 개선 계획](../implementation/v0.2-rag-quality-improvement-plan.md)을 따른다.

## 남은 확인

- 사전 판정 전환 뒤 v0.2 OPS·SHOP 합성 평가로 거절 회귀를 확인한다(판정 54/60 이상, 근거 없는 오답 0/10, 충돌 10/10, 총 US$1 상한).
- 15문항 전체와 거절 확인 질문 N1~N5를 질문마다 새 대화로 다시 측정한다.
- 이전 대화 참고를 켜면 이력이 근거 예산을 줄여 근거가 잘린다. 이력과 근거 중 무엇을 우선할지 결정이 필요하다.
- Q08(흩어진 규칙과 표 행 조합), Q09(같은 순위 안 추첨 누락)는 아직 해결되지 않았다.
- 독립·블라인드 평가와 대규모 자료 검증은 아직 없다.
